# Coast band organic terrain (WI-06d-a)

## Summary

The coast band (band 1) was the last band to use greybox terrain. WI-06d-a
replaced the manual polygon definitions with organic slabs generated by
`generateOrganicSlab`. The coast band now uses the same organic terrain
generation as the deeper bands, producing band-consistent terrain with
irregular edges (request §14.3).

## Key Facts

- **Affected shapes:** `west-wall-slab`, `wall-slab`, `ridge-slab`, `seal-slab`
  — all replaced with `slab(id, x, y, w, h, band)` calls.
- **Unchanged shape:** `seabed-floor` — kept as-is because it has a special
  open-ended shape with a descent notch that cannot be represented as a
  simple slab.
- **Band parameter:** coast band uses band=1, which gives the least roughness
  (0.15) and smoothest edges of all bands.

## How to Generate Organic Terrain

Use the `slab()` helper in `worldData.ts`:

```typescript
slab('shape-id', x, y, w, h, band);
```

This calls `generateOrganicSlab`, which:
1. Creates a rectangular collision shape (4 points)
2. Generates an organic visual outline with jitter (many more points)

The band parameter controls roughness: band 1 (coast) is smoothest, band 5
(hadal) is roughest.

## Tests

`src/world/coastOrganicTerrain.test.ts` verifies that all coast band terrain
shapes have organic visual outlines (>4 points) and are closed organic slabs.
