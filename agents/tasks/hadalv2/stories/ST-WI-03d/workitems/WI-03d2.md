# WI-03d2 — Tier 4: section 52 rendering passes + browser spot-checks

## Goal

Give the tier-4 organisms WI-03d1 defines their presentation: extend the
existing WI-02b spine renderer pipeline (no new renderer architecture) with
the section 52 scale techniques the private designs need, all reading
simulation state only (section 13; the renderer never changes rules), and
prove the presentation in the tier's browser spot-checks — one large and one
colossal organism — including the section 34 performance guard.

## Deliverables (checkable)

- Spine renderer extension for very long bodies: section 34 moderate spine
  segment counts, pooled particles, no per-frame allocation in the
  large-creature render hot paths.
- The presentation half of the section 52 techniques, each reading the
  simulation state WI-03d1 exposes:
  - partial anatomy (A): the body is only ever partially realized on screen;
  - parallax crossing (B): a parallax pass for presences that cross behind
    or through the player's view without being centered;
  - foreground pass (C): a foreground occluder pass so the presence reads as
    larger than the scene it crosses;
  - sonar scale (E): the sonar-scale readout of the simulation signal
    WI-03d1 defines (echo at impossible scale);
  - no center framing (G): the camera/scene never frames the presence
    centered; no boss intro, no letterboxing, no cutscene framing.
- AC-roster-large presentation half (final proof owner here): the browser
  spot-checks show the colossal presence reading through its techniques, and
  the no-full-view encounter never presents a clean full-body view on screen.

## Browser spot-checks (presentation only)

- One large and one colossal organism: render, animate, and read as large
  without console errors. The colossal reads through its techniques, not
  through a centered boss intro.
- Performance guard: the largest tier-4 scene stays smooth in a focused
  browser inspection (section 34). The definitive 60 FPS check in the
  largest encounter remains ST-07's job.
- No browser reachability proof (section 70 layers): all behavior evidence
  is headless in WI-03d1; these checks are presentation-only.

## Tests and checks

- Spoiler containment for this item's artifacts: no creature name or secret
  description appears outside debug internals and the private content files
  (the tier's AC-roster-tests half; the roster-wide audit finalizes in
  WI-03d3).

## Constraints, assumptions, non-goals

- No new renderer architecture; no simulation rule changes in this item. If
  a section 52 technique forces a new rendering architecture, extend in
  place under the WI-02b renderer and note it in the evidence. Falsified if
  a technique needs gameplay rules in the renderer — move it to the
  simulation (WI-03d1's territory) instead.
- No production world data placement (WI-03d3); no authored spectacle beats
  (ST-04); no ending content (ST-05).
- Spoiler rules (sections 0, 12, 68): internal ids only in identifiers,
  tests, and commit messages ("added the large-creature presentation passes"
  style).
