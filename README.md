# HADAL

A 2D side-scrolling underwater exploration game in the browser, built
with TypeScript, Vite, and Three.js (request §28).

> This is the development skeleton. The full spoiler-safe README —
> controls, browser requirements, expected playtime, save location, and
> the separated developer section — arrives with the handoff pass
> (WI-17, request §69).

## Install

```bash
npm install
```

## Run (dev server)

```bash
npm run dev
```

Open the printed localhost URL in a desktop browser (WebGL, 1080p).

## Build

```bash
npm run build
npm run preview
```

## Test

```bash
npx vitest run
```
